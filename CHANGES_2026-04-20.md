## 1. Tier content-limit system

New file: [src/lib/tierLimits.js](src/lib/tierLimits.js)

Defines per-tier *content caps* that sit **alongside** (not replacing) the existing `TOOLS_BY_TYPE_TIER` tool-visibility map in [src/pages/CardStudio.jsx](src/pages/CardStudio.jsx).

```js
// Shape exported by getTierLimits(tier, { isArtist })
{
  maxImages,
  allowMusic,
  allowVideoBackground,
  allowGradientBorder,
  allowAnimatedBorder,
  allowOpenEffects,      // confetti / hearts / etc. on reveal
  allowAmbientEffects,   // background particles
  allowCustomFonts,
  allowGifts,
  allowQuestions,
  allowTypewriter,
  allowFadeIn,
  envelopeProfile,       // 'basic' | 'premium' | 'elite'
}
```

### Tier matrix

| Cap | Classic | Premium | Elite | Artist |
|---|---|---|---|---|
| Music | ✗ | ✓ | ✓ | ✓ |
| Video background | ✗ | ✓ | ✓ | ✓ |
| Gradient border | ✗ | ✓ | ✓ | ✓ |
| Animated border | ✗ | ✗ | ✓ | ✓ |
| Open effects | ✗ | ✓ | ✓ | ✓ |
| Ambient effects | ✗ | ✓ | ✓ | ✓ |
| Custom fonts | ✗ | ✓ | ✓ | ✓ |
| Gifts | ✗ | ✗ | ✓ | ✓ |
| Questions | ✗ | ✗ | ✓ | ✓ |
| Typewriter | ✗ | ✓ | ✓ | ✓ |
| Fade-in | ✓ | ✓ | ✓ | ✓ |
| Max images | 1 | 3 | 8 | ∞ |

**Rules**
- `content` tool has **no** limits at any tier (heading / body / extended text always fully editable).
- Classic is intentionally very limited — it's the free tier.
- Artists bypass every cap via `getTierLimits(tier, { isArtist: true })`.

Also exported: `shouldShowEnvelope(studioType)` — returns `true` only for `moment` and `chain`. Other types skip the envelope metaphor entirely.

## 3. Preview gating (CardPreviewModal)

[src/components/CardPreviewModal.jsx](src/components/CardPreviewModal.jsx)

New prop `tierLimits` (nullable — `null` = public viewer, show everything).

Helper: `const limit = (key, fallback = true) => (tierLimits ? !!tierLimits[key] : fallback)`.

Features now gated by `limit(...)`:

| Feature | Gate |
|---|---|
| Music `<audio>` element | `limit('allowMusic')` |
| Video backdrop | `limit('allowVideoBackground')` |
| `renderBgEffect()` | `limit('allowAmbientEffects')` |
| Gradient border in `renderGradientBorder()` | `limit('allowGradientBorder')` |
| Animated border in `renderGradientBorder()` | `limit('allowAnimatedBorder')` |
| `triggerOpenEffect()` (confetti) | `limit('allowOpenEffects')` |
| `hasQuestions` | `limit('allowQuestions')` |
| `hasGift` | `limit('allowGifts')` |
| `hasFadeIn` | `limit('allowFadeIn')` |
| `hasTypewriter` | `limit('allowTypewriter')` |
| `primaryImage` | `maxImages > 0` |

These gates **stack on top of** `toolAllowed(id)` — a feature renders only when both tool visibility and tier cap allow it.

## 4. Envelope now type-gated

The envelope / wax-seal reveal only renders for **Personal** (`moment`) and **Chain** (`chain`) cards. Poll, Trivia, and Anonymous jump straight to the open card.

Changes:

- [src/components/CardPreviewModal.jsx](src/components/CardPreviewModal.jsx) — initial stage is `envelopeEnabled ? 'closed' : 'open'`; `fadeBody` / `bodyVisible` default to `!envelopeEnabled`; `handleReset()` respects the same rule; the `<Envelope>` block is wrapped in `stage === 'closed' && envelopeEnabled`.
- [src/pages/CardView.jsx](src/pages/CardView.jsx) — entry-stage condition changed from `!isOpen` to `!isOpen && shouldShowEnvelope(cardType)`.

If a future change needs to add an envelope to another type, update the `ENVELOPE_TYPES` set in [src/lib/tierLimits.js](src/lib/tierLimits.js) — single source of truth.
